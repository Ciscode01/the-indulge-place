# The Indulge Place

Restaurant website source code.

- `public/`: customer-facing website and admin dashboard
- `api/`: menu and order API endpoints
- `migrations/`: PostgreSQL database schema
- `seed.sql`: starter menu categories

**Hosting note:** GitHub stores the source code but does not run the backend or database. The API currently uses the Hatchable runtime and PostgreSQL, so those services must remain hosted or be migrated separately for a fully working public website.
