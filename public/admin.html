Restaurant dashboard

The public website is hosted on GitHub Pages. GitHub Pages supports the customer-facing website, but it does not run the private database or restaurant management API required for editing menu items and managing incoming orders.

Customer orders: Customers can build an order and send it directly to the restaurant through WhatsApp. The restaurant must confirm availability, delivery fees and payment with the customer.

Menu administration: Menu changes are currently made in the GitHub repository. A secure admin dashboard requires a separately hosted backend and database before it can be enabled.
